# ImgSentry

Optimize and compress images, convert to WebP/AVIF, and organize your WordPress media library — all in one plugin.

## Requirements

Node.js 18+, npm

## Build

Run `npm ci` then `npm run build`. The build writes the compiled files to imgsentry/build/ ; the WordPress plugin is the imgsentry/ folder.

## Install

Zip the imgsentry/ folder including build/ and upload it, or copy it to wp-content/plugins/.
